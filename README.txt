ЗАПУСК БОТА QULAY (пилот)
==========================

Токен и ключ Firebase уже вставлены в bot.py — ничего менять не нужно.

ШАГИ:

1. Установи Python 3.10 или новее (если ещё нет): python.org/downloads

2. Открой командную строку (cmd / PowerShell) в папке с этими файлами
   (bot.py и serviceAccountKey.json должны лежать РЯДОМ, в одной папке)

3. Установи библиотеки:
   pip install python-telegram-bot firebase-admin

4. Запусти бота:
   python bot.py

5. Если всё ок — в консоли появится "Бот запущен..."
   Открой своего бота в Telegram, нажми /start

ВАЖНО:
- Бот работает, пока запущен скрипт (окно консоли открыто)
- Если закроешь консоль — бот перестанет отвечать
- Для постоянной работы 24/7 нужен отдельный хостинг — скажи, если понадобится, разберём отдельно

БЕЗОПАСНОСТЬ:
- Файл serviceAccountKey.json даёт полный доступ к базе — никому не пересылай,
  не публикуй на GitHub. Если случайно "утечёт" — перевыпусти новый ключ в
  Firebase Console (Settings → Service accounts → Generate new private key)
  и замени файл.
